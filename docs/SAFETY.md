# AllergyBridgeの安全方針

## 1. 安全不変条件（最優先・例外なし）

1. **安全・飲食可否を断定しない。** `safe` / `edible` / `allergen_absent` 等の判定フィールド・UI文言を作らない。
2. **メニューに書かれていないことを非含有の根拠にしない。** 記載なしは常に `unconfirmed`（未確認）。
3. **3区分を型と画面で区別する。** `menu_mentions`（メニュー記載候補・AI読み取り）/ `ai_inferred`（AI推測）/ `unconfirmed`（未確認）。すべて店員確認が必要（`confirmationRequired: true`）。
4. **AIの読み取り原文も検証済み情報ではない。** `readText.readBy` は常に `"ai"`。誤読の可能性を画面で示す。
5. **記載の種類を区別する。** `contains_claim` / `absence_claim` / `possible_presence` / `ambiguous`。`absence_claim`（「不使用」等）は**メニュー上の主張にすぎず安全判定ではない**。
6. **文字列一致は整合性確認にだけ使う。** excerpt と readText の一致は、実際の原材料の検証ではない。
7. **選択した全アレルゲンを結果に含める。** 欠落は `unconfirmed` / `not_assessed` で補う。
8. **未知の状態・不正出力は安全側に倒す。** スキーマ違反や不変条件違反は通さない（`AI_FAILED` 等）。
9. **画像内の文字はデータであり命令ではない。** プロンプトインジェクションを実行しない。
10. **AIの自由文はプレーンテキストとして表示する。** `dangerouslySetInnerHTML` は禁止（ESLintで強制）。
11. **確認カードは検証記録のある文言だけを表示する。** 機械翻訳（Gemini含む）は検証方法として認めない。`draft` は表示しない。
12. **AIが使えなくても確認カードは使える。** どのエラーでもカード単独利用の導線を残す。
13. **画像・個人情報を保存しない。** 画像はメモリ内処理のみ。ログに画像・AI出力本文を出さない。アレルギー設定は端末内のみ。
14. **秘密情報をコミットしない。** APIキーは使わない（Vertex AI は ADC）。`.env*` は `.env.example` 以外コミット禁止。
15. **Mockデータを本番で実解析として出さない。** Mockは `NODE_ENV !== "production"` かつ `MOCK_GEMINI=true` のときのみ。Mock応答は `dataOrigin: "mock_fixture"`。
16. **対応外のアレルゲン・言語組み合わせを、対応しているかのように見せない。**

禁止語の検出は補助策にすぎない。安全性は上記の型・サーバー検証・UI・テスト・人による評価で多層的に担保する。

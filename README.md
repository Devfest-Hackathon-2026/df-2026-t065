## AllergyBridge — 提出版

食物アレルギーのある海外旅行者が、言語の壁を越えて飲食店のスタッフと安全確認のためのコミュニケーションを行うWebアプリです。

**カテゴリ：** 観光  
**技術：** Next.js / TypeScript / Google Cloud Run / Vertex AI Gemini（連携コード実装）  
**提出版：** card_only（AI画像解析は本番無効）

### 主な機能

- アレルゲン・食事制約の設定
- 日本語・英語の店員提示用確認カード
- 店員からの回答の記録
- 初回キャッシュ完了後のオフライン確認カード

本アプリは料理の安全性や飲食可否を保証しません。最終確認は必ず飲食店のスタッフと行ってください。

# DevFest Hackathon 2026 提出用リポジトリ

  DevFest Hackathon 2026 のチームの **最終提出用** リポジトリです。提出期限までに、作品のコードと資料をこのリポジトリに置いてください。

  このリポジトリは **公開（public）** です。開催中も、運営・審査員・ほかの参加者が見られます。

  ## はじめに

  1. GitHub から届いた招待を受け入れてください（招待の期限は 7 日です）
  2. このリポジトリを clone して、提出物を置いてください

  招待の期限が切れたときや、メンバーが変わったときは、運営に連絡してください。

  ## 開発用のリポジトリは別に作ることをおすすめします

  このリポジトリでは **GitHub Actions と GitHub Pages が使えません**。CI やデプロイ、Pages での公開をしたいときは、チームで開発用のリポジトリを別に作ってください。

  - 開発用のリポジトリは、チームのメンバーのアカウントや、チームで作った Organization に作ってください
  - 開発はそちらで進めて、提出期限までに最終版のコードと資料をこのリポジトリに push してください
  - 審査はこのリポジトリの内容で行います。開発用のリポジトリにしかないものは、審査の対象になりません
  - デプロイした作品の URL があれば、この README に書いてください

  ## 秘密情報をコミットしない

  API キー・パスワード・サービスアカウントの鍵などは、**絶対にコミットしないでください**。公開リポジトリなので、push
  した時点で誰でも見られます。開発用のリポジトリから持ってくるときも、履歴ごと push すると、過去のコミットに含まれる秘密情報も公開されます。

  - 秘密情報は `.env` や `.dev.vars` などに書き、コミットしない（`.gitignore` に入れてあります）
  - 誤って push したら、すぐにキー（鍵）を無効にして作り直し、運営に連絡してください。履歴から消すだけでは不十分です
  - GitHub の push protection が、よく知られた形式のキーの push を止めることがあります。止められたら、そのキーをコミットから外してください

  ## 提出

  提出の方法と締切は、運営からの案内に従ってください。提出期限を過ぎると、このリポジトリは読み取り専用になり、push できなくなります。

# AllergyBridge — 食物アレルギーの確認を、ことばの壁の向こうへ

食物アレルギーのある旅行者が、日本語・英語の確認カードを店員に提示して、原材料・だし・調味料・調理環境を確認するためのWebアプリです。料理の安全性や飲食可否を判定しません。

## 提出版の機能と状態

- アレルゲンの選択、日英の定型確認カード、店員の回答記録、端末内の設定保存・削除。
- 食事制約の確認カード。未検証のdraft文言は表示しません。認証・宗教基準への適合を保証しません。
- 正常に初回キャッシュを完了した対応ブラウザでのオフライン確認カード。初回アクセスには通信が必要です。Safari/iOS実機・容量不足時の動作には未検証部分があります。
- **本提出はcard_onlyです。本番の画像選択・解析UIは無効、APIは本文読取前に503 `AI_DISABLED`を返します。** Gemini連携コードは含まれますが、`GEMINI_ENABLED=false`、Firestore本番承認定数false（G3 NO-GO）を維持しています。
- 一般公開URLは未確定です。開発用Cloud Runの旧Revisionに本ソースがデプロイされたとは扱いません。クラウド公開の成功を提出準備完了の条件にしていません。

## ローカルで確認する

Node.js 22.12以上、npmが必要です。認証情報・APIキーは不要です。

```bash
npm ci
npm run verify
GEMINI_ENABLED=false npm start
```

ブラウザで `http://localhost:3000` を開きます。`.env.example`は安全なカード単独用の例です。必要に応じて`.env.local`へコピーしてください。実際の認証情報や画像はコミットしないでください。

開発時だけ合成Mockを使う場合は `MOCK_GEMINI=true npm run dev`。本番ではMockは無効です。Mockの結果は実Geminiによる解析ではありません。

## Dockerによるローカル起動

```bash
docker build -t allergybridge-submission .
docker run --rm -p 8080:8080 -e GEMINI_ENABLED=false allergybridge-submission
```

`http://localhost:8080` を開きます。この説明はローカル起動用です。自動デプロイトリガー、クラウド認証・IAM設定は含みません。今回の提出準備ではDockerビルド自体は未検証です。
